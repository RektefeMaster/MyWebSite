# METEK quality gates (before release)

Use as the checklist behind proof points `documented-quality-gates` / `quality-checks-before-handoff`.

Projects are reviewed against these gates before release (documented practice — not an absolute guarantee of zero exceptions).

## Required

- [ ] **Performance:** Critical pages load acceptably on mobile; no obvious blocking assets left unaddressed
- [ ] **Accessibility (core):** Text contrast where feasible, focus states, alt text on meaningful images, keyboard reach for primary actions
- [ ] **Technical SEO:** Title/description present, one clear H1, sensible heading order, crawlable links, basic metadata
- [ ] **Functional:** Primary conversion path works (contact, quote, book, WhatsApp, etc.)
- [ ] **Handoff:** Client can update agreed content surfaces (CMS/panel) or knows the update path

## When copy is in scope

- [ ] Clarity / UX writing pass
- [ ] Search intent aligned only where the page weight allows
- [ ] No Forbidden claims from `proof-points.md`
- [ ] Locale copy is native-quality (not literal translation)
