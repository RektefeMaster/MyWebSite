VOICE PROFILE
=============
Author: Nurullah Aydın / METEK Digital
Goal: Credible studio copy that sells custom web + systems work without agency sludge
Confidence: medium (source-derived from studio facts + portfolio; refine after golden batch)

Source Set
- content-system/brands/metek/proof-points.md
- Live portfolio projects (WCC, Nacar, Wuuf, residence/hotel, bots, CRM)
- lib/site.ts contact constants

Rhythm
- Short to medium sentences; fragment OK in hero lines
- Avoid stacked clauses that sound translated

Compression
- Dense on deliverables; light on mood adjectives

Capitalization
- Conventional; brand METEK Digital / M.

Parentheticals
- Rare; for constraint or clarification only

Question Use
- Rare; CTAs prefer imperatives (“Start a project”, “View work”)

Claim Style
- Proof-tied; no unearned superlatives

Preferred Moves
- Name the artifact (site, panel, bot, CMS)
- Name the user action (quote, WhatsApp, book)
- Name the constraint (mobile speed, SEO prep, one team)
- single-accountability: one delivery lead discovery→launch (not marketplace handoff)

Banned Moves
- innovative solutions, seamless, cutting-edge, leverage, delve
- outcome-driven / design-led as empty badges
- “not a pitch deck” style meta jokes
- Fake metrics

CTA Rules
- One primary action; WhatsApp as alternate path where already used
- Promise scope/next step — not a manifesto

Channel Notes
- Site UI: compressed
- Case study: slightly longer, still concrete
- Blog: expert, specific, non-fluffy
- Email/WhatsApp prefill: plain and human
