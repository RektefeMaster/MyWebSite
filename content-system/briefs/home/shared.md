# Home — shared semantic brief

```yaml
page_goal: Establish METEK as a founder-led studio that designs and builds durable websites, admin panels, and automation — then move the visitor to work or contact.
primary_audience: [boutique_brand, global_vertical, ops_panel]
visitor_problem: Needs a digital presence or system that does not look like a template and will hold up in daily use.
main_message: Idea to working product — custom design and solid engineering from one team.
proof_points: [1, 2, 3, 4, 5, 6]
required_information:
  - What we build (sites, panels, automation)
  - Selected work proof
  - How we work (short)
  - Clear CTA to start + alternate WhatsApp
desired_action: View selected work or start a project (email/WhatsApp).
search_intent: Branded / navigational + light discovery for custom web studio (SEO weight 10%).
tone_constraints: Confident, concrete, short; no agency badges.
claims_not_allowed: [ROI numbers, awards, team size inflation, theme marketplace]
constraints:
  headline_max_chars: 48
  support_max_chars: 140
  button_max_chars: 22
  mobile_lines_target: 3
```
